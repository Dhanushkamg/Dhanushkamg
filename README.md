## 🚀 Featured Projects

### 🌟 TechNest Platform (Personal Project)
A full-stack technology products e-commerce platform built with **React 19, Vite, TypeScript, Java 21, and Spring Boot**.
- **Key Features:** JWT-based authentication, customer/admin role-based access control (RBAC), product and inventory management, cart & wishlist, coupon system, and order processing.
- **Payments:** Secure **PayHere** payment gateway integration with backend transaction verification and idempotent webhook handling.
- **State & Data:** TanStack Query & Zustand for performant client-side state management.

An enterprise-grade pharmacy supply chain management platform connecting customers, pharmacists, suppliers, and administrators.
